# Fonts

Self-hosted OFL faces, subset to Cyrillic and Latin, then axis-sliced so the whole set stays under 150 KB.

| Family | File | Axis | Source |
| --- | --- | --- | --- |
| Unbounded | `unbounded-cyrillic.woff2`, `unbounded-latin.woff2` | wght 500–700 | [@fontsource-variable/unbounded](https://fontsource.org/fonts/unbounded) 5.3.0 |
| Onest | `onest-cyrillic.woff2`, `onest-latin.woff2` | wght 400–600 | [@fontsource-variable/onest](https://fontsource.org/fonts/onest) 5.3.1 |
| JetBrains Mono | `jetbrains-mono-cyrillic.woff2`, `jetbrains-mono-latin.woff2` | wght 400–500 | [@fontsource-variable/jetbrains-mono](https://fontsource.org/fonts/jetbrains-mono) 5.3.0 |
