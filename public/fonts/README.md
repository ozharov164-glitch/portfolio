# Fonts

Сейчас сайт использует системный стек (sans + mono).

Чтобы подключить легально полученные локальные файлы:

1. Положите `.woff2` в эту папку, например `public/fonts/Display.woff2`.
2. Добавьте `@font-face` в `src/styles/globals.css`.
3. Не подключайте Google Fonts, CDN и любые внешние URL шрифтов.
