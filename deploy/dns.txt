DNS для купленного домена → GitHub Pages

Подставьте свой домен вместо example.com.
Логин GitHub подставьте вместо USERNAME.

A-записи для корня домена (example.com):
  185.199.108.153
  185.199.109.153
  185.199.110.153
  185.199.111.153

CNAME для www:
  www  →  USERNAME.github.io

Свой домен в GitHub: Settings → Pages → Custom domain.
HTTPS GitHub включает сам, обычно в течение нескольких часов.
Не используйте запись вида *.example.com
