DNS: portfoliodekha.ru → GitHub Pages
Регистратор домена — Beget. Сайт живёт на GitHub Pages, не на хостинге Beget.

Не нажимайте в меню домена:
  «Направить на сайт или VPS»
  «Сертификат на домен»
  «Получить AuthInfo-code»
  «Передать домен на другой аккаунт»

Нужный пункт: «Редактировать DNS».

Удалите старые A-записи корня и www (они смотрят на Beget).
Не трогайте MX, если почта Beget ещё нужна. Записи вида *.portfoliodekha.ru не нужны.

A для корня (хост @ или пусто):
  185.199.108.153
  185.199.109.153
  185.199.110.153
  185.199.111.153

AAAA для корня (по желанию, тоже @):
  2606:50c0:8000::153
  2606:50c0:8001::153
  2606:50c0:8002::153
  2606:50c0:8003::153

CNAME для www:
  www  →  ozharov164-glitch.github.io

В GitHub: Settings → Pages → Custom domain = portfoliodekha.ru
и галочка Enforce HTTPS. Для сборки через Actions CNAME-файл сам домен не включает.

HTTPS выдаёт GitHub (Let's Encrypt), не сертификат Beget.
После смены DNS замок может появиться от нескольких минут до нескольких часов.
