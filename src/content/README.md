# Контент сайта

Все тексты, ссылки и пути к медиа живут здесь — не в компонентах.

## Placeholders

В `site.ts` замените:

| Ключ | Назначение |
| --- | --- |
| `[[NAME]]` | Имя в шапке, футере, title |
| `[[TELEGRAM_URL]]` | Полная ссылка, например `https://t.me/handle` |
| `[[TELEGRAM_HANDLE]]` | Публичный handle для подписи |
| `[[EMAIL]]` | Почта для mailto |
| `[[GITHUB_URL]]` | Профиль или репозиторий. Пока стоит placeholder — ссылка GitHub скрыта |
| `[[TIMEZONE]]` | Например `UTC+3` |
| `[[DOMAIN]]` | Купленный домен без `https://`. При сборке подставит sitemap/robots и CNAME для GitHub Pages |
| `[[YEAR]]` | Год в футере |

В `projects.ts` для каждого кейса:

- `localVideo` — путь вида `/media/<id>/demo.webm`. Пустая строка или placeholder скрывает кнопку «Смотреть короткое демо» и Play на постере.
- `youtubeUrl` — полная ссылка на запись. Пустое значение скрывает «Запись на YouTube». Сейчас заполнены FADELINE, ВключиСебя и резюме-бот; ОптБот ещё пустой.
- `githubUrl` — ссылка на код. Пустое значение скрывает «Код / GitHub».
- `poster` — локальный SVG/PNG/WebP в `public/media/<id>/`.

Не вставляйте внешние URL картинок и не добавляйте iframe.
